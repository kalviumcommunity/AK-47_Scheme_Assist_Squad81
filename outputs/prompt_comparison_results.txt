PART 1: SYSTEM VS. USER ROLES ARCHITECTURE
--------------------------------------------------------------------------------
1. 'system' Role : Defines global behavioral persona, operational scope, tone,
                   length constraints, and refusal/fallback policies.
2. 'user' Role   : Carries the specific query, task instructions, or turn input.
Key takeaway: System prompts enforce safety, grounding, and formatting across all
turns, preventing user prompts from hijacking the assistant's operational scope.

[Variation B: Role-Constrained & Specific (Recommended Production Prompt)]
Description    : System role enforces Role, Scope, 2-3 sentence constraint, and Fallback. User prompt is specific and targeted.
System Message :
Role: You are SchemeAssist, an official AI assistant guiding citizens and staff on government welfare schemes.
Scope: Answer only questions regarding scheme eligibility, application procedures, required documentation, and benefits. Do not provide legal advice or speculate on unverified rules.
Constraints: Respond in 2-3 concise sentences using plain, objective language. Avoid jargon or conversational filler.
Fallback: If the question is outside government schemes or if information is unknown/insufficient, reply strictly with: 'I do not have sufficient verified information to answer this question. Please consult the official department portal or helpdesk.'
User Message   :
What are the eligibility criteria and required documents for the Pre-Matric Scholarship scheme for minority students?
Response Output:
To qualify for the Pre-Matric Scholarship, students must belong to a notified minority community, be studying in Classes 1 through 10, and have an annual family income not exceeding Rs. 1 Lakh. Required documents include verified proof of income, community/minority certificate, previous academic marksheet, and student bank account details.
Metrics        : Chars=341 | Words=49 | Tokens: Prompt=136 (Sys=117, Usr=19), Reply=67, Total=203

Scope: Extract and summarize scheme information accurately from verified guidelines.
Constraints: Respond ONLY with a valid JSON object matching the exact schema below. Do not include markdown formatting or commentary.
JSON Schema:
{
  "scheme_name": "string",
  "target_beneficiary": "string",
  "eligibility_summary": "string (max 2 sentences)",
  "required_documents": ["string"],
  "fallback_flag": boolean

Fallback: If information is missing or question is out of scope, set 'fallback_flag' to true.

PART 4: CHOSEN PROMPT DOCUMENTATION & JUSTIFICATION (Task 4)
--------------------------------------------------------------------------------
CHOSEN PROMPT: Variation B (Role-Constrained SchemeAssist System Prompt)

WHY THIS PROMPT WORKS BEST:
1. Explicit Scope: Restricts responses to government welfare schemes, preventing hallucinations
   and out-of-domain conversational drift.
2. Length & Tone Constraint: Enforces 2-3 sentence limit in plain, accessible language, saving
   token cost and reducing cognitive overload for citizens and helpdesk staff.
3. Safe Fallback Mechanism: Prevents speculative guessing when information is incomplete,
   directing the user safely to the official department portal.
4. Clear System/User Separation: The system message controls rules and boundaries while the user
   message supplies the scheme query, creating a predictable and reproducible interaction.
