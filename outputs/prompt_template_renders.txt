SAMPLE 2: FEATURE_1_CHAT_PATH
Description  : Interactive Citizen Chat Assistant turn using SCHEME_QA_TEMPLATE_V2
Template     : scheme_qa (v2.0.0)
System Message Render:
You are SchemeAssist, the official AI assistant specializing in government welfare schemes, eligibility rules, and application procedures.
Tone & Style: Objective, citizen-friendly, and concise
Grounding Rules:
- Answer strictly from the provided context guidelines.
- If the answer is not present in the context, respond strictly with: 'I do not have sufficient verified information in the official guidelines to answer this query.'
- Citation Requirement: Cite official scheme circulars, portal links, or eligibility clauses whenever available.

User Message Render:
Role: SchemeAssist welfare guidance specialist

Context Information:
"""
# Knowledge Base Document: Government Welfare Schemes Overview

## Overview
This knowledge base contains official notifications, circulars, and guidelines regarding government welfare assistance programs across departments.

## Primary Objectives
- Discoverability: Enable citizens and helpdesk executives to search and identify applicable welfare schemes.
- Eligibility Guidance: Explain specific age, income, occupation, category, and demographic qualifications.
- Application Enablement: Provide clear documentation checklists, step-by-step application instructions, and official portal links.
"""

Citizen Question: What documentation do I need to prepare for scheme application?

Instructions:
1. Base your answer strictly on the context provided above.
2. If the context does not contain the answer, reply with: "I do not have sufficient verified information to answer this question. Please consult the official department portal."
3. Keep the response to 2 to 3 sentences.
4. Format requirements: Plain text with bulleted points for lists of documents or criteria.

Model Output / Finding:
A citizen should check eligibility criteria (such as income, age, and residency) and ensure all required identity documents are ready before applying.

=====================================================================================
ARCHITECTURE SUMMARY:
1. Centralization : Prompts live exclusively in `prompts/` (e.g. templates.py, answer.py).
2. Reusability    : One template definition serves Chat, Batch CLI, and Evaluator.
3. Maintainability: Wording fixes or citation rules are modified once and propagate everywhere.
4. Safety         : Missing placeholders are caught at runtime via TemplateValidationError.
